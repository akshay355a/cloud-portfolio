## ⚡ Features & Highlights

- **Neo-Brutalist Aesthetics**: Bold typography (`Space Grotesk`, `DM Mono`, `DM Sans`), high-contrast borders, solid drop shadows, and vibrant color blocking.
- **Interactive Live Terminal**: Custom-built typing typewriter shell simulating live AWS deployment health checks and stack verification with replay controls.
- **Ambient Floating Shapes**: Smooth continuous floating physics animations for background Neo-Brutalist decorative blobs and rings.
- **Featured Projects Grid**: Equal-sized 3-column project showcase with direct repository links:
  1. *Netflix Clone DevSecOps Deployment on Amazon EKS*
  2. *TechStore Three-Tier AWS E-Commerce Platform*
  3. *Multi-Disease Prediction System with Mistral LLM*
- **Dedicated Tech Stack Breakdown**: Categorized into Cloud & Infra, Networking, Monitoring & Security, Containers & CI/CD, and Systems & Languages.
- **Verified Credentials & Experience**: Direct verification links for AWS Certified Cloud Practitioner on Credly, IBM Python certification, and Elewayte AI/ML internship certificate.
- **Zero Heavy Framework Dependencies**: Pure Vanilla HTML5, CSS3, and JavaScript for blazing fast load times and clean responsiveness.

## 🚀 Running Locally

Clone the repository:
```bash
git clone https://github.com/AKSHAY355-a/cloud-portfolio.git
cd cloud-portfolio
```

Start a local static server:
```bash
# Using Python
python -m http.server 8000

# Or using Node.js npx serve
npx serve .
```

Open your browser at `http://localhost:8000`.
